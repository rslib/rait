# RAIT

RAIT is a command-line tool that gives coding agents a stable, token-efficient interface to local PDFs and documents: PDF metadata, text, search, rendering, splitting, merging and OCR, DOCX, PPTX, EPUB and HTML as Markdown with headings, lists and tables, previews of CSV, TSV, Excel, ODS and Parquet tables, image info, conversion, shrinking and OCR, and listing, reading and safe extraction of zip, 7z, ar and tar archives (plain, gz, zst, xz or bz2).

RAIT follows the [AXI (Agent eXperience Interface)](https://axi.md/) principles for agent-ergonomic CLIs:

- TOON output with small default fields. More on request with flags such as `--fields`.
- Long text is truncated, with the total size and the exact command to get the rest.
- Errors go to stdout as structured records with a code and a fix. Unknown flags are rejected, and the error lists the valid ones.
- Empty results say so. List output ends with `help` next steps.
- `rait` with no arguments shows live state, not a manual.

## Quickstart

Install from a clone. This needs Rust 1.96 or newer.

```sh
cargo install --locked --path crates/rait
rait pdf info tests/fixtures/simple.pdf
```

Expected output:

```text
count: 1
pdfs[1]{file,pages,title,encrypted}:
  tests/fixtures/simple.pdf,1,null,false
help[2]:
  Run `rait pdf text <file> --pages <range>` to read text
  Run `rait pdf search <file>... "<query>"` to find lines
```

`pdf text` detects tables from word positions and writes them as Markdown tables. `rait pdf tables` and `rait doc tables` return tables as rows keyed by their header:

```sh
rait pdf tables tests/fixtures/tables.pdf --pages 1
```

Read a document as Markdown, one part per section, slide or chapter:

```sh
rait doc text tests/fixtures/sample.docx --parts 2
```

Preview a table: sheets, column types, then rows as a table:

```sh
rait table info tests/fixtures/sample.xlsx
rait table schema tests/fixtures/sample.csv
rait table rows tests/fixtures/sample.parquet --rows 1-5 --columns region,revenue
```

Output is [TOON](https://toonformat.dev/) by default. Add `--format json` when a script parses it.

## External programs

`rait doc`, `rait table`, `rait archive` and `rait image info|convert` are built in and need nothing else. PDF commands wrap proven local tools that RAIT does not bundle. Run `rait doctor` to see what is installed and the install command for anything missing.

| Program | Used by | Without it |
| --- | --- | --- |
| Poppler (`pdfinfo`, `pdftotext`, `pdftoppm`) | `info`, `text`, `search`, `render` | `info`, `text` and `search` use a built-in reader with a warning; `render` fails |
| `qpdf` | `split`, `merge` | fails with `dependency_missing` |
| `ocrmypdf` | `pdf ocr` | fails with `dependency_missing` |
| `tesseract` | `image ocr` | fails with `dependency_missing` |

## Use it from an agent

Install the embedded skill for your agent:

```sh
rait skills install --target claude             # ~/.claude/skills/rait
rait skills install --target pi --scope project # .agents/skills/rait
```

Run `rait` with no arguments to see the live home view: dependency status, PDFs and documents in the current directory and the next commands to try.

## Reference

`--help` is the reference. Every command lists its flags and examples, for example `rait pdf text --help`.

## Development

Enable the pre-commit hook once per clone. It runs `cargo fmt --check`, `cargo clippy -D warnings` and `cargo test`, the same checks as CI.

```sh
git config core.hooksPath .githooks
```

`skills/rait/SKILL.md` is generated from the guide in `crates/rait/src/guide.rs`. After changing the guide, regenerate it:

```sh
RAIT_BLESS=1 cargo test -p rait
```

Document and table fixtures under `tests/fixtures/` are generated by `tests/fixtures/make-documents.sh` (pandoc) and `tests/fixtures/make-tables.sh` (uv, openpyxl and pyarrow) and `tests/fixtures/make-pdf-tables.sh` (pdflatex) `tests/fixtures/make-images.sh` (uv and Pillow) and `tests/fixtures/archives/make-archives.sh`. CI uses the committed files and needs none of these tools.
